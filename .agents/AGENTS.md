## Version Changelog Rule

On every version change, you MUST update the `version_log.md` file in the root of the workspace.

- The `version_log.md` should be updated or cleared entirely to reflect only the most recent changes for the new version.
- Ensure the changelog is written in simple, plain English that is easy for non-programmers to understand. Avoid overly technical jargon when describing bug fixes or feature additions.
- ignore the new generated key`swhich point to the new releases.
- Leave explanations away, just write the changelog.

## Security Key Rule

- Never give out the security key.
